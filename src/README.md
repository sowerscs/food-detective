# Food Detective source

The app is one self-contained index.html built from these parts in this order:

    cat 01-head.html 02-data.js 03-lessons.js 04-state.js 04b-sync.js 05-render.js 07-camera.js 08-report.js 09-xlsx.js 06-actions.js > ../index.html

Bump APP_VERSION in 04b-sync.js and version.json together on every release so open devices update themselves.
